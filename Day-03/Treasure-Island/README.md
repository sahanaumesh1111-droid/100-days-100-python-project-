# Day 4 - Treasure Island 🏝️

## About
A text-based adventure game built using Python conditionals.

## How to Play
- Choose left or right at the crossroads.
- Decide whether to wait for a boat or swim across the lake.
- Choose a door: red, yellow, or blue.
- Make the right choices to find the treasure!

## Concepts Learned
- `if`, `elif`, and `else`
- Nested conditional statements
- `input()` and `print()`
- String methods such as `.lower()`
