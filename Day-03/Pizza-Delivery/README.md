# Day 3 - Python Pizza Deliveries 🍕

## About
A Python program that calculates the final pizza bill based on the customer's choices.

## How it works
- Choose a pizza size: Small, Medium, or Large.
- Choose whether to add pepperoni.
- Choose whether to add extra cheese.
- The program calculates the final bill.

## Pricing
- Small pizza: $15
- Medium pizza: $20
- Large pizza: $25
- Pepperoni: $2 for Small, $3 for Medium or Large
- Extra cheese: $1

## Language
Python
