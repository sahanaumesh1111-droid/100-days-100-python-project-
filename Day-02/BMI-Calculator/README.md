# Day 2 - BMI Calculator

## About
A Python project that calculates Body Mass Index (BMI).

## How it works
1. Enter your weight in kilograms.
2. Enter your height in metres.
3. The program calculates your BMI.
4. based on BMI classify as underweight or overweight or normal weight

Python
